# CHOESENSE CLAUDE CODE (9-ROUTER) & ANTIGRAVITY SYSTEM SPEC
Project: Predictive Flood-Risk & Cross-Jurisdiction Civic Accountability Mesh (Tri-City)
Stack: FastAPI (Python 3.11), Supabase (PostgreSQL + PostGIS + Realtime), scikit-learn, React (Vite + Tailwind + Leaflet.js + Chart.js), Twilio WhatsApp API.

Core Rules:
1. Seed Data: Always preserve the 6 documented points (McDonald's Chowk Zirakpur, TDI City Sec 71, Phase 3B Mohali, Sec 40/41 N-Choe Chandigarh, Airport Rd Ballomajra, Kharar-Landran Rd).
2. Jurisdiction Routing: Route tickets via Supabase RPC route_ticket_by_gps across Chandigarh MC, GMADA, Zirakpur MC, and NHAI.
3. Explainable ML: Output risk level (Low/Medium/High/Critical) + feature contribution breakdown (Rainfall vs Elevation vs 0.5 in/hr Drain Capacity). Never use opaque black-box claims.
